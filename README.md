# Illinois Tech Eta Kappa Nu Site

Source code of the official site of Eta Kappa Nu's Delta Chapter at Illinois Tech.

Built using [Astro](https://astro.build)

Builds run daily at 5:17 AM CST. This is when events are pulled from the Outlook calendar and placed on the website.

Builds also run on any commit to the main branch. Thus, work on the site should be done in other branches, then merged with the main branch.
